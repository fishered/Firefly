# 从 Firefly 1.2.0 升级到 1.2.1

1.2.1 保持 Executor v1/v2、插件 API level 1、任务定义、租户准入、公平队列和核心数据库 schema 版本 12 兼容。

## 升级

1. 备份数据库，执行对应方言的 v21 feature migration，或由首个 1.2.1 节点以 `initialize-if-empty` 安装。
2. 滚动升级控制面节点。1.2.0 节点忽略新表并继续准入/派发；报告会把跨版本窗口标记为 `MIXED_VERSION`。
3. 全部节点升级后等待至少一个完整分析窗口，再使用下调建议；混合窗口期间只查看证据或上调。
4. 检查容量 flush 延迟、丢弃和失败指标，并确认 v21 表按保留期有界增长。

## 回滚

回滚到 1.2.0 只需停止 1.2.1 sampler；v21 新表可以保留。不要删除或回退 1.2.0 的 policy、usage、reservation 和公平状态。预演和报告接口在旧版本上不可用，既有 `GET/PUT /api/tenants` 保持不变。
